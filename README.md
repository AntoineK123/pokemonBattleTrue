# 🎮 Mini Pokémon Battle (MVP)

Un mini-jeu en ligne permettant de simuler des combats entre deux Pokémon directement dans le navigateur.

Testez par vous même ici -> https://antoinek123.github.io/pokemonBattleTrue/  😉

## 🚀 Description

Ce projet est un MVP (Minimum Viable Product) d’un jeu de combat Pokémon simplifié.  
L’utilisateur sélectionne deux Pokémon, puis lance un combat entre eux.

⚠️ Particularité actuelle :  
Le jeu fonctionne entièrement côté client (frontend only) — aucun serveur n’est utilisé, et l’utilisateur contrôle les deux adversaires.

---

## 🧠 Fonctionnalités Principales

- Choix des deux pokemons qui s'affrontent 
- Simulation d'un combat tel le vrai jeu Pokemon
- Système de tour par tour
- Bande sonore incluse rapellant l'univers Pokemon
- Calcul des dégâts simplifiés
- Attaques avec bonus selon le type de pokemon adverse (feu++/herbe, eau++/feu ...) 
- Interface interactive ne nécessitant pas de rechargement

## 🧠 Fonctionnalités Secondaires

- Consultation du pokedex pour avoir les détails des pokemons (en cours)
- Liste des regles (en cours)

---

## ⚙️ Stack technique

- Structure : Organisation du code similaire à un projet React 
- Langage : JavaScript  
- UI : Aucune libraire, toutes les Cards sont "artisanales"


---

## 🕹️ Utilisation

1. Choisir deux Pokémon  
2. Lancer le combat  
3. Cliquer pour enchaîner les actions  
4. Observer le résultat du combat  

---

## ⚠️ Limitations (MVP)

- Un seul joueur contrôle les deux Pokémon  
- Pas de backend → aucune persistance des données  
- Logique de combat simplifiée (pas de types, statuts, talents, etc.)  
- Pas encore d'objet dans le combat (paralysie, endormissement ...)
---

## 🔮 Améliorations prévues

- Des objets pouvant changer le statut de l'adversaire (endormi, ...)
- Avatar des pokemons mobiles lors des attaques
